# AI Readiness Audit Rules

## AI-READY-001 Missing Agent Entry Point

Severity: medium

Detect missing AI instructions or handoff documents.

Expected artifacts:

- AGENTS.md
- HANDOFF.md
- STATUS.md
- DECISIONS.md

## AI-READY-002 Missing Validation Context

Severity: medium

A repository should document how an agent verifies changes.

## AI-READY-003 Hidden Project Context

Severity: high

Critical project knowledge should not exist only in chat history.

## AI-READY-004 Unclear Ownership Boundary

Severity: medium

Document dangerous areas and files requiring care.
