# AI Readiness Review Skill

## Purpose
Assess whether a repository can be understood and continued by AI coding agents.

## Checklist

- AGENTS.md exists when needed
- HANDOFF.md exists for active projects
- STATUS.md records current state
- DECISIONS.md records important choices
- Architecture documentation exists
- Validation commands are documented
- Known risks and non-goals are explicit

## Output

Return:

- readiness_score
- missing_context
- evidence
- remediation
- confidence
