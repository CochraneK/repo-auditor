# AI Readiness Review Skill

## Purpose

Assess whether a repository can be understood, changed, validated and handed off by a new AI coding agent without relying on temporary conversation state.

## Checklist

- README provides purpose and quick start;
- README exposes a meaningful architecture/flow visual when useful;
- AGENTS instructions define operating constraints;
- lightweight or full handoff entry exists;
- STATUS records current state;
- DECISIONS records important choices;
- architecture documentation exists;
- validation commands are exact and executable;
- blockers, non-goals and do-not-break areas are explicit;
- canonical source of truth is distinguishable from generated dashboards/summaries;
- public-safe continuity excludes credentials, hidden reasoning and unnecessary sensitive data;
- full ARIS4C-style continuity package is recognized when present but is not mandatory for trivial repositories.

## Output

Return:
- readiness_score;
- readiness_state;
- continuity_profile;
- checks;
- findings;
- evidence;
- remediation;
- confidence.

AI readiness is an onboarding/continuity dimension, not an overall repository quality score.
