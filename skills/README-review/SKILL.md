# README Review Skill

## Purpose
Evaluate whether a repository README is understandable for humans and AI agents.

## Checklist

- Clear one sentence identity
- Problem and purpose explained
- Demo or visual evidence when applicable
- Quick start available
- Architecture explained
- Status and roadmap visible
- License and contribution information
- AI handoff information available

## Output
Return structured findings:

- evidence
- severity
- confidence
- remediation
- auto_fixable
