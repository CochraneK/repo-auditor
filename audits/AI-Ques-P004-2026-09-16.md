- `p004/core.js` 中 `p005Observer:false`；

## 仍然 open 的 P1

### AQ4-P1-003 · `?admin=1` 不是授权 — **OPEN · external-blocked**

现在 UI 已诚实写明这只是 research-preview/demo，但任何知道 query parameter 的人仍能打开。

真正关闭这个 finding 需要：

- authenticated backend；
- RBAC；
- server-side field filtering；
- 普通用户浏览器根本不收到 clinical/admin fields。

静态 GitHub Pages 无法独立解决。

### AQ4-P1-004 · Safety 是关键词 fallback，不是生产 Safety Agent — **OPEN · external-blocked**

当前优点是：

- 角色扮演会让位于安全回复；
- 文档已降级为“best-effort keyword fallback”，不再把它描述成成熟 Safety Agent。

但固定关键词仍不能可靠覆盖：

- 同义/含蓄表达；
- English / multilingual；
- negation/context；
- 复杂风险语义。

真正关闭需要独立 safety classifier / policy layer + 测试集。
