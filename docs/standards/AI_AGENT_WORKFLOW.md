# AI Agent Workflow Standard

## Goal

Make repositories executable by both humans and AI agents.

## Lifecycle

Inventory
→ Understand
→ Plan
→ Modify
→ Validate
→ Review
→ Handoff

## Agent Roles

### Explorer
Maps repository structure and risks.

### Builder
Implements approved changes.

### Reviewer
Challenges assumptions and verifies evidence.

### Maintainer
Decides release readiness.

## Principle

No important project knowledge should exist only inside a temporary conversation.
