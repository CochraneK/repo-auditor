# AI Agent Handoff Standard

## Goal
Make repositories transferable between AI agents without relying on chat history.

## Recommended files

- AGENTS.md: operating instructions
- HANDOFF.md: current mission and next steps
- STATUS.md: current state
- DECISIONS.md: architectural decisions
- CHANGELOG.md: historical changes

## Minimum handoff content

1. What is this project?
2. What is completed?
3. What is blocked?
4. What should the next agent do?
5. How can changes be validated?
6. What should not be broken?
